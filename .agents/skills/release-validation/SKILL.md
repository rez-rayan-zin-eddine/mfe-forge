# Release validation

## When to use

Explicit release, publish, PR merge, or CI workflow work.

## Inputs and context required

Version policy, workflows, package graph, changesets, and requested release scope.

## Procedure

1. Confirm authorization. 2. Check versions and package consistency. 3. Run release checks without publishing first. 4. Inspect CI workflows. 5. Report what was and was not externally executed.

## Verification

Full relevant checks, git status, and explicit external-action evidence.

## Expected artifacts

Release checklist, changeset/workflow edits, and publication status.
