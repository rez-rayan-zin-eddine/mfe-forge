# Documentation sync

## When to use

When commands, APIs, workflows, or architecture change.

## Inputs and context required

Changed behavior, existing docs, CLI help, and relevant ADRs.

## Procedure

1. Search README/docs/package READMEs. 2. Compare claims to source and help. 3. Update only evidenced behavior. 4. Add an ADR for durable decisions. 5. Remove stale promises.

## Verification

Docs build or link check where available, plus CLI help inspection.

## Expected artifacts

Updated docs, ADR, and list of audited claims.
