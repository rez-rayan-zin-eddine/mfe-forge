# mfe-forge

## 0.1.0

First release of the `0.x` development line under new ownership (repository: rez-rayan-zin-eddine/mfe-forge). Versions `2.0.0`–`8.1.0` were prototype releases and are deprecated; all six packages are versioned together.

### Minor Changes

- Harden `mfeforge.config.ts` loading (comments, imports, type annotations, `as`/`satisfies`, `defineConfig<T>()`), warn instead of silently ignoring a broken config, and keep `.mfeforgerc.json` valid when saving.
- Make host `vite.config.ts` remote registration idempotent in `generate` and `sync`, and warn when the `remotes` block cannot be found.
- Add project inspection commands: `status`, `graph`, `inspect`, `deps`, `check`, `migrate`, and the generated `mfe-forge.manifest.json`.
- Fix `mfeforge.config.js` files generated by `init` being ignored (ESM default export was not unwrapped), so `defaults.packageManager` and other settings now apply.
- Generate package-manager-correct workspace scripts and next-step hints (`npm run dev --workspace=…`, `npx mfe …`).
- Move `typescript` to devDependencies and drop unused runtime dependencies (`node-fetch`, `listr2`, `yaml`, `globby`, `semver`).
