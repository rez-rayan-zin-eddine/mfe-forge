# Getting help

- **Documentation:** https://rez-rayan-zin-eddine.github.io/mfe-forge/
- **Questions and ideas:** [GitHub Discussions](https://github.com/rez-rayan-zin-eddine/mfe-forge/discussions)
- **Bugs:** [open a bug report](https://github.com/rez-rayan-zin-eddine/mfe-forge/issues/new?template=bug_report.yml) and include the output of `npx mfe-forge doctor --json`.
- **Security issues:** see [SECURITY.md](SECURITY.md); do not open a public issue.
